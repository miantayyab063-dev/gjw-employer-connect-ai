# GJW Employer Connect AI — User-Friendly v3

## What changed
- Guided home page with 4-step workflow and quick action links
- Dedicated Help & Guide screen with FAQs
- Improved navigation, keyboard focus, accessible labels, responsive layout, mobile-friendly tap targets
- Clear warnings on contact permission and sending eligibility
- All original backend functions preserved

## Installation
Follow `INSTALL.md` in this folder. Deploy `public/` as document root, keep `private/` outside public access, and import `sql/schema.sql`. Do not place database credentials in public directories.

## Important limitations
This is a UI/UX improvement, not a verified production release. Real API integrations, Hostinger deployment, contact discovery, delivery, database operations and browser rendering have not been end-to-end tested. Existing functionality and limitations from v2 still apply.
